# ExcelManus 使用指南

## 能做什么
- 读取与分析工作区中的 xlsx / xlsm / csv / tsv：总览、区域内容、SQL 汇总、规则校验。
- 修改工作簿：写值与公式、增删行列与工作表、样式、条件格式、数据验证、图表；另存与格式转换、按列拆分。
- 管理文本文件与目录：新建、编辑、复制、移动、删除（删除进入回收站，可恢复）。
- 批量或复杂计算用沙箱脚本完成；大任务可以拆给多个子代理并行处理。
- 记住用户偏好与业务口径（记忆），遵守用户设置的规则。

## 设置在哪
- 右上角「设置」：模型档案（添加 API Key、测试连接、探测能力）、订阅账号登录、规则、记忆、技能、MCP 服务器、通用设置（默认权限模式、子代理并发数、代理）。
- 权限模式：confirm（写入也要审批）、standard（写入自动并先备份，删除与外部调用需审批）、auto（全部自动）。
- 每次修改已有文件前都会自动备份，可在文件面板的备份中找回。

## 限制
- 不执行任意命令行程序；脚本只在隔离沙箱中运行，不能访问网络与工作区外文件。
- 工作簿中引擎不认识或会丢失的对象（如部分透视表、宏的修改）会拒绝写入并说明原因，不会静默丢失。
- 截图渲染目前不可用；图片内容只有在模型支持视觉时才能被识别。
- 只能访问工作区内的文件；`.excelmanus/` 内部目录不可见。

回答用户时直接说明怎么做，必要时指出设置入口。
