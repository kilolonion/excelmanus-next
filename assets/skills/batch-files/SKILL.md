# 多文件批量处理

## 判断是否拆分
- 文件 ≤ 3 个或每个文件改动很小：自己顺序处理，或用 `run_script` 一次完成。
- 文件多且每个需要读取、判断再修改：拆给子代理并行。
- 需要跨文件对比的任务不拆分写入，只拆分读取。

## 分工
1. 用 `find` 列出全部目标文件，确认数量与范围，必要时先问用户。
2. 每个子代理负责一组互不重叠的文件，派生时用 files 参数声明它负责写入的文件（获得写入租约，避免两个代理写同一文件）。
3. 任务说明写清：处理哪些文件、要做什么、输出放在哪里、完成标准、遇到问题怎么办（发消息给父代理，而不是自己猜）。
4. 只读分析类子任务用 reader 角色；需要写入用 worker。
5. 子代理数量不必超过文件组数；系统会按并发上限自动排队。

## 汇总
- 用 `agent_wait` 等待全部完成；每个子代理结束时会自动汇报最终回复与变更摘要。
- 汇总时核对：每个文件都有结果；失败的列出原因；需要时用 `agent_status` 查看细节。
- 最终回复给出总体结果、每个文件的状态和输出位置。
