# 批量实例

## 同名文件

输入 north/sales.xlsx 与 south/sales.xlsx，输出保留目录结构或稳定来源前缀，例如输出/north/sales.xlsx 和输出/south/sales.xlsx。不能都覆盖输出/sales.xlsx。

## 分工合同

任务示例：处理附件清单中的华东组，统一日期显示并新增按月汇总表；保留源明细。验收每个文件的明细行数不变、汇总合计等于有效明细合计。输出放指定组目录。结构不符合模板时记录失败原因，不猜列映射。

分工清单字段：输入路径、规则组、输出路径、执行者、处理状态、源行数、输出行数、源合计、输出合计、核验结论、失败原因。

## 中断恢复

5 个输入中 3 个已核验、1 个失败、1 个未处理。只重试失败和未处理项，先确认已有输出状态。不要把已经乘过税率的 3 个文件再次乘税率，也不要把失败文件计入成功总额。
