# 数据核对

## 步骤
1. **确定匹配键**：看两份数据的结构，找出唯一标识（单号、编码、日期+金额组合）。键不唯一时先报告重复键，请用户决定处理方式。
2. **规范化再比较**：键两边的格式要一致（去空格、统一大小写、日期统一），否则会产生大量假差异。
3. **三类结果**：用 `workbook_analyze` 的 SQL 分别找出：
   - 只在 A 中存在；
   - 只在 B 中存在；
   - 两边都有但数值不同（列出每个不同字段的 A 值、B 值、差额）。
4. **容差**：金额比较默认容差 0.01；用户有要求按用户的。
5. **输出**：新建「差异报告」工作表或文件，每类结果一个区域，开头写汇总（总条数、匹配数、各类差异数、差额合计）。原始数据不修改。
6. **说明**：回复中给出结论与最大的几项差异，并引用报告中的区域。

## 常见陷阱
- 一对多匹配（一张发票对应多笔付款）要先按键汇总再比较。
- 四舍五入差异与真实差异要分开报告。
