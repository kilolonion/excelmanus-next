# 数据清洗

交付可解释的清洗结果与处理统计。规则应服务用户的目标，清洗不能悄悄改变业务含义。

## 诊断与决策

- 识别表头、明细范围、字段用途和问题分布。`workbook_read` 用于观察样本和实际内容，`workbook_analyze` 可做字段画像；不能只看前几行就假定整列类型一致。
- 区分标识符与度量：前导零编码、身份证、银行卡号、超长数字标识保留文本。数字外观不意味着可求和；已经丢失的前导零不能凭猜测补齐。
- 日期先确定源格式。03/04 不能默认解释成 3 月 4 日；文本日期、Excel 序列值和带时区时间需分别处理。无法确定的条目进入待确认清单。
- 去重前选择业务键和保留规则。完全相同行与同键但金额不同是两类问题；后者可能是修订记录或合法明细，不能直接保留第一条。
- 空值、零值、空字符串和“未知”分别统计。缺失值填充、异常值删除、模糊名称合并需有业务依据；用户未指定时保留并标记待确认。

## 执行方法

先在代表性样本上验证转换规则，再按字段批量应用。可选公式、SQL 或 `run_script`；工具与 SDK 的参数和发布语义以当前工具说明为准。没有明确覆盖要求时，可输出清洗副本或辅助列；用户要求原位修改时保留必要的原值对照。

规则冲突时处理到可确定的范围，把剩余问题具体列出；不为“问题数量归零”而填造数据。

## 交付检查

回读结果，核对处理前后行数、删除的重复数、失败转换数和关键金额合计。每条转换都有可解释的归属；去重以外的格式清洗不应改变记录数。说明修改字段、采用规则、保留的问题和结果位置。

遇到重复键与模糊日期时，读取 [清洗实例](references/examples.md)。
