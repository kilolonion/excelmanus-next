# 数据清洗

## 步骤
1. **诊断先于修改**：用 `workbook_analyze` 统计每列的空值数、不同值个数、类型分布，找出问题列，并把诊断结果简要告诉用户。
2. **确认范围**：要修改的列和行范围不确定时，用 `ask_user` 的区域确认题型请用户在表格上确认。
3. **逐类处理**：
   - 去重：先说明按哪些列判定重复、保留哪一条（第一条/最新一条），删除前报告重复条数。
   - 日期：统一为一种格式；无法解析的值不要猜，单独标记。
   - 文本：去首尾空格、全角转半角；不要改变含义（如"有限公司"与"有限责任公司"不要自动合并）。
   - 数字：文本型数字转为数值；千分位、货币符号去掉后再转。
   - 拆分/合并列：新列放在原列右侧，保留原列直到用户确认。
4. **标记而不是删除**：空值、异常值默认用底色标记（如浅黄），而不是直接删除或填充；填充规则需要用户同意。
5. **复核**：修改后再统计一次，确认问题数量下降、总行数符合预期。

## 常见陷阱
- 大批量修改前，改动超过数千个单元格时优先用 `run_script` 一次完成，避免多次往返。
- 身份证号、银行卡号、以 0 开头的编码必须保持文本，不能转成数字。
