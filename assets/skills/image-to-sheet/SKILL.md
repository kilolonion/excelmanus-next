# 图片转可编辑表格

交付结构可编辑、值可追溯的工作表。目标不是像素复刻，而是准确还原表格含义；用户要求版式复刻时再考虑样式细节。

## 识别与不确定性

- 使用 `read` 读取原图；确定是单张表、跨页表、票据还是多个独立表。裁切、模糊、旋转和缺页会影响结构判断，先识别这些限制。
- 区分多层表头、合并标题、数据行、合计和脚注。空白格可能代表缺失、合并延续或真实空值，不能一律向下填充。
- 编码保留前导零和原始长度；金额区分千分位、小数点、负号与括号负数。单位在标题或脚注时应一起记录。
- 无法确定的字符保留空白或明确待确认标记，并建立“来源位置—疑似值—原因”清单。不要凭合计倒推造出模糊的明细。

## 生成与对照

可以先用一小块确认结构，再用 `workbook_edit` 新建或写入目标表。数字、日期和文本按识别到的含义设置，保留原图中重要的表头层级；不要把全部内容压成一列文字。

新建文件可直接指定 `sheetNames:["收款收据"]`，在同一批次写入内容与样式；需要核对表时将它也列入名称列表。省略名称列表时默认只有一张 `Sheet1`，也可用 `sheet.rename` 改名。不要先删除 `Sheet1`，也不要猜测存在 `Sheet2` 等表。多工作表的每个区域必须显式带表名；新增表不会自动切换后续写入目标。

如果新建失败，按回执修正参数，不再次提交相同失败操作。若直接工具调用连续重复错误参数，改用 `run_script` 的 `wb.edit` 提交明确的改名和写入操作；先确认目标是否已经创建，已有文件不要再次 `create:true`。脚本读取结果在 `result.data`，不是结果对象顶层。金额与合计用公式或脚本计算；布局一次批量设置后截图，只修正实际看到的问题，不反复重设相同格式。

用 `workbook_read` 回读实际值，借助 `workbook_render` 对照原图的行列位置、缺行缺列与格式。视觉对照与数值校验互补：截图看起来相似不证明金额正确。大图分块核对时保持来源坐标，防止重叠区重复录入。

## 完成标准

核对可识别数据行数、列数、关键编码和金额；有合计时独立求和比较，票据大小写金额可交叉核验。未决项逐条列出，说明哪些数据尚不可使用。视觉能力或渲染端缺失时说明当前无法完成的步骤，不声称已对照通过。

遇到字符歧义与跨图重叠时，读取 [识别实例](references/examples.md)。
