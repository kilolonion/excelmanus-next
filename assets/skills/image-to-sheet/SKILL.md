# 截图转表格

## 步骤
1. **识别**：用 `read` 读取图片，识别表格的行列结构、表头与合并单元格；先告诉用户识别到几行几列。
2. **生成**：用 `workbook_edit` 新建工作簿（或新工作表），按原结构写入：表头一行，数字写成数值，日期写成日期，看不清的单元格留空并标黄。
3. **截图对照**：用 `workbook_render` 渲染生成的区域，与原图逐行对照，找出不一致的单元格。
4. **修正**：至少对照修正一次；仍不确定的值在回复中列出，请用户确认。
5. **格式**：还原原图中明显的格式（表头加粗、合计行、金额格式），不追求像素一致。

## 常见陷阱
- 数字 0 与字母 O、1 与 l、逗号与小数点容易混淆，金额要核对合计。
- 票据的大写金额与小写金额应一致，可用来校验。
