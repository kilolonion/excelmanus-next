# 报表制作

## 步骤
1. **确认口径**：先用 `workbook_read` 看总览与样本行，确认维度列（地区、部门、月份）与度量列（金额、数量）。口径不明确（含税/不含税、按下单日还是回款日、是否剔除退货）时先问用户，不要自己假设。
2. **汇总**：用 `workbook_analyze` 的 SQL 汇总，不要逐行手算。先跑一次不保存的查询核对行数与合计，再保存结果。
3. **输出位置**：新建汇总工作表（或新文件），不要改动原始数据表。工作表名写清内容，如「按地区汇总」。
4. **图表**：
   - 类别比较用柱状图；时间趋势用折线图；占比且类别 ≤ 6 个用饼图，否则用条形图。
   - 图表标题写清指标与期间；坐标轴带单位。
5. **格式**：表头加粗并加底色；金额列用千分位两位小数；百分比列用百分比格式；首行冻结。
6. **核对**：交付前用 `workbook_analyze` 的 check 核对汇总合计与原表合计一致；有差异先查原因再交付。

## 常见陷阱
- 原表有合计行时，汇总前要排除，否则会重复计算。
- 文本型数字（左对齐、带空格）会被 SQL 当成文本，先确认列类型。
- 日期列混有文本日期时，按月汇总前先统一格式（见 data-cleaning）。

交付时用一两句话说明口径、输出位置和核对结果。
