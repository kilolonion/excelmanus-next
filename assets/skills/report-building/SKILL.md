# 汇总报表与图表

目标是交付口径明确、数字可追溯的报表。用户只要一个合计或改一个表头时，可以直接完成，不必展开整套流程。

## 判断与方法

- 从输入中识别明细粒度、维度、度量、期间和单位。订单金额与回款金额、含税与不含税、自然月与财务月会得到不同结果；只澄清影响当前结论且无法从数据确定的口径。
- 汇总前识别原表中的小计、总计、退货、重复单据和文本数字。明细与小计混算会重复计数；缺失值与零值应分别处理。计算方法可选 SQL、公式或批量脚本，按数据规模与用户要求选择。
- 默认将汇总放在独立区域或工作表以便追溯；用户明确要求更新原报表时沿用其位置和结构。列出期间、单位、分组字段及采用的过滤规则。
- 报表布局按阅读顺序安排：关键指标、分组明细、解释。图表只呈现确有比较意义的指标；类别比较常用条形/柱状图，时间变化用折线图。占比图需要统一分母；缺失期间不能自动解释为零。
- 数字格式匹配指标含义与单位，不把显示舍入后的值重新作为计算输入。沿用用户模板；没有模板时保持表头、合计、正文层次清楚。

## 核验与交付

用独立汇总或规则校验复核总数：源明细有效行数、各分组合计、输出总计应能相互解释。过滤前后的差异要有原因；重点检查空分组、负值和边界日期。写入后用 `workbook_read` 回读实际结果；`workbook_analyze` 可用于汇总和核验，具体调用以工具说明为准。

交付指出结果位置、口径、合计与核验结果；未能计算或核验的指标明确列出，不把写入成功当成数字正确。

需要处理小计混入、日期边界或交叉汇总时，读取 [汇总实例](references/examples.md)。
