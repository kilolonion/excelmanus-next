# 汇总实例

## 明细混有小计

输入：华东明细 100、200，紧接“华东小计”300；华南明细 50。
用户要求按地区汇总明细。

先确认小计行可由字段/结构识别，排除小计后得到华东 300、华南 50、总计 350。直接对金额列求和会得到 650。输出保留真实地区名称，记录排除了一行小计。若“小计”也可能是合法客户名，不能仅凭文本全表删除。

## 月份与比率

1 月最后一天和 2 月第一天分别归属各月；原始时间含时区时按业务时区判定。毛利率应以汇总毛利除以汇总收入，不能简单平均各行毛利率。分母为零时标记无可解释比率。

## 核验表

可记录有效明细行数、排除行数、源金额合计、分组金额合计、差值。差值非零时先定位口径差异，不能为了相等而修改源数据。
