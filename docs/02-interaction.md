# 02 交互设计

本文描述用户看到和操作的一切。视觉风格、组件库、动画属于【开放】；信息架构、交互流程与状态语义属于【推荐】；标【硬性】的是与数据安全或产品承诺直接相关的交互。

## 1. 设计原则

1. **同一张表，两个人在看**：用户与代理共享同一个工作簿视图。代理的每一个动作（看了哪里、打算改哪里、改了哪里）都能在表格上找到对应位置。
2. **先看见，再同意**：任何需要用户确认的写入，都先在表格上预览效果，再让用户决定。
3. **不打断正在做的事**：代理的界面切换是"建议"，用户正在编辑或查看其他内容时不强行跳转。
4. **状态来自服务端**：界面上的"执行中、排队中、已完成、中断"等状态只来自服务端事件，前端不自行推测。

## 2. 整体布局

### 2.1 桌面布局（宽度 ≥ 1280px）

```
┌──────────┬───────────────────────────────────┬────────────────────┐
│ 侧栏      │ 表格工作台                          │ 对话面板            │
│ ─ 会话    │ ┌ 文件标签页 ─────────────────────┐ │ ┌ 会话标题/模型 ──┐ │
│ ─ 文件    │ │ 工具栏 / 公式栏                  │ │ │ 消息流          │ │
│ ─ 代理团队│ │ 表格画布（代理活动叠加层）          │ │ │                 │ │
│          │ │ 工作表标签                        │ │ │                 │ │
│          │ └────────────────────────────────┘ │ ├ 待审批/提问条 ──┤ │
│ 设置入口  │ 变更导航条（本轮改动 3/17 ◀ ▶）       │ │ 输入框           │ │
└──────────┴───────────────────────────────────┴────────────────────┘
```

- 未打开任何工作簿时，对话面板居中占满主区域（"对话优先"）。
- 打开工作簿后自动切换为"表格 + 对话"分栏，分栏比例可拖动并记住。
- 用户可折叠对话面板（表格全屏）或折叠表格（对话全屏）。
- 侧栏的"代理团队"页在会话有子代理时出现。

### 2.2 窄屏布局（768–1279px）

表格与对话变为标签页切换，对话输入框在表格页底部保留一个迷你输入条。v1 最小支持宽度 1024px；768px 布局为手机端预留（P2），v1 保证不崩溃即可。

## 3. 对话面板

### 3.1 消息流中的块

一条助手消息由若干块组成，按时间顺序排列：

| 块 | 显示 | 交互 |
| --- | --- | --- |
| 思考 | 默认折叠，显示"思考了 N 秒" | 展开查看 |
| 正文 | Markdown，表格、代码高亮 | 单元格/区域引用（如 `Sheet1!B2:D9`）可点击定位并高亮 |
| 工具调用卡片 | 工具名的中文标签、参数摘要、状态（等待参数/执行中/成功/失败/未执行/结果不确定） | 展开查看完整参数与结果；表格工具卡片提供"在表格中查看" |
| 待办清单 | 步骤与完成状态 | 实时更新 |
| 子代理卡片 | 子代理名、任务、状态、最近动作 | 点击进入该代理的视图 |
| 审批/提问结果 | 用户做了什么决定 | — |
| 重试提示 | 模型接口重试中（第 2/5 次，3 秒后） | — |
| 错误指引 | 错误类别、原因、可执行的下一步（如"去设置检查密钥"、"换一个模型重试"） | 按钮直达 |
| 变更摘要 | 本轮实际修改的文件、工作表、单元格数、新增对象 | 点击逐项定位 |
| 文件交付 | 代理提供的下载文件 | 下载、在工作台打开 |
| 用量 | 本轮输入/输出/缓存 token | 悬停查看 |

**工具调用状态的判定【硬性】**：

- 参数仍在流式生成：等待参数。
- 模型流中断导致调用从未进入执行：**未执行**（灰色），不是失败。
- 进入执行后进程重启、结果未知：**结果不确定**（黄色），提示"请检查文件后再继续"。
- 执行完成：成功或失败，以工具返回为准。

### 3.2 用户消息

- 显示附件缩略图、引用的文件与区域徽标。
- 运行中追加的消息显示派发状态：`引导 · 等待下一步` / `打断 · 正在停止当前任务` / `排队 · 前面还有 2 条` / `已生效` / `已撤回` / `失败`。
- 排队中的消息可撤回；撤回后内容回到输入框。

### 3.3 输入框

- 多行输入，`Enter` 发送、`Shift+Enter` 换行（可设置）。
- **上下文徽标区**（输入框上方）：
  - 当前选区徽标：`📌 销售.xlsx · Sheet1!B2:F40`，用户在表格中改变选区时自动更新；可移除；可"钉住"（不再随选区变化）。
  - `@` 引用的文件、区域、技能徽标。
  - 附件缩略图。
- `@` 弹出候选：文件（工作区内模糊搜索）、区域（当前打开工作簿的工作表与已命名区域）、技能。
- `/` 弹出命令：内置命令 + 可由用户调用的技能。
- 发送按钮：空闲时是"发送"；代理运行中变为"发送（引导）"并带下拉菜单切换本条的派发策略；旁边独立的"停止"按钮。
- 粘贴图片、粘贴文件、拖入文件都进入附件；拖入工作区中已有文件则变成 `@文件` 引用而非重复上传。
- 输入草稿按会话保存在本地，刷新不丢。

### 3.4 待处理交互条

待审批、待回答的问题固定显示在输入框上方（而不是只在消息流里），同一时间可能有多个（来自不同代理），按时间排列，每条标明来自哪个代理。

## 4. 代理与表格的联动

这是产品差异化的核心。

### 4.1 区域引用可点击

对话中所有出现的区域引用（正文、工具卡片、提问）都是可点击的：

- 悬停：表格上以虚线框预览该区域（若该文件已打开）。
- 点击：打开对应文件、切换工作表、滚动到区域并高亮 2 秒。
- 引用带修订号时，如果文件已变化，悬停提示"该引用基于旧修订，内容可能已变"。

### 4.2 代理活动叠加层

表格画布上方有一个不影响编辑的叠加层，显示代理活动：

| 状态 | 样式（示意） | 来源 |
| --- | --- | --- |
| 正在读取 | 浅蓝色虚线框，淡出 | `workbook_activity` 增量与 `presence` |
| 计划修改 | 橙色虚线框 + 角标"待确认" | `workbook_activity` 增量与 `presence`（需审批的写入、`dryRun` 预览、代理的 `present` 高亮提示） |
| 已修改 | 绿色底色，单元格角标小点 | 来自同步通道的 `doc.op`（本轮实际写入结果，不是模型自述） |
| 冲突 | 红色边框 | 写入因区域冲突被拒的区域 |
| 其他代理正在处理 | 带代理名称和颜色的细边框（类似协作编辑的光标） | `presence` |

- 叠加层可以一键隐藏。
- "已修改"高亮保留到用户点击"已查看"或开始下一轮。
- 工作表标签上用小圆点标记该表有本轮修改。

### 4.3 提问时让用户在表格上选择【硬性：确认结果必须绑定修订号】

`ask_user` 工具（见 [06 §5](06-tools.md#5-交互工具3-个)）支持以下题型，前端需分别实现：

| 题型 | 表现 |
| --- | --- |
| 单选/多选 | 选项按钮，可附"其他"自由输入 |
| 自由文本 | 文本框 |
| **区域确认** | 代理给出建议区域（如"我识别到数据区是 A1:H240，表头在第 1 行，对吗？"）。表格自动打开并以橙色框高亮建议区域；提问卡片显示"确认此区域 / 我来重新选择 / 取消"。选择"重新选择"后，用户直接在表格上拖选，卡片实时显示新区域，点"确认"提交 |
| **区域选取** | 代理不给建议，只说明需要什么（如"请选择要汇总的列"）；可限定单个/多个区域、是否限定在某工作表 |
| **修改确认** | 代理给出拟修改内容（由 `dryRun` 生成），表格上以预览层显示修改后的值（原值可悬停查看）；卡片提供"应用 / 修改后再应用（回到对话说明）/ 取消" |

提交的答案包含：文件、工作表、区域、该文件在用户确认时的修订号。代理拿到答案后如果修订号已变化，写入会因区域冲突被拒，需要重新读取——这防止"用户确认的是旧内容"。

### 4.4 写入审批在表格上预览

权限模式要求审批的写入（见 [04 §5](04-agent-runtime.md#5-权限与审批)）：

1. 审批请求到达时，若目标工作簿已打开，表格上显示预览层（新值、新格式、新增/删除的行列、插入的图表占位框）。
2. 审批条显示：`代理想修改 销售.xlsx · Sheet1!C2:C240（238 个单元格）`，按钮：`批准` / `拒绝` / `本会话同类操作自动批准`，另有"查看详情"展开参数。
3. 拒绝时可附一句理由，理由会返回给代理。
4. 未打开工作簿时，只显示审批条，提供"在表格中预览"。

### 4.5 变更导航与查看原值

每轮结束（或用户随时）可以打开变更导航条：

- 列出本轮所有被修改的区域（按文件、工作表分组），`◀ ▶` 逐个跳转。
- 选中已修改单元格时，侧边小窗显示"修改前：xxx"（来自修改前备份，见 [07 §7](07-workbook-engine.md#7-修改前备份)）。
- 提供"用备份替换当前文件"入口（整文件级，不做单元格级回退），替换前二次确认。

### 4.6 从表格发起对话

- 右键菜单："问代理…"（打开输入框并附上当前选区）、"解释这个公式"、"检查这列数据"、"用这个区域画图"。快捷项清单可配置，每项本质是一段预置提示词 + 选区上下文。
- 选中单元格时，公式栏旁有一个小按钮"问代理"。

### 4.7 用户与代理同时编辑【硬性】

- 代理运行中，用户可以正常编辑表格，不加锁。用户编辑与代理写入只要区域不重叠，就互不影响、不冲突（区域级一致性模型见 [03 §6](03-architecture.md#6-一致性模型硬性)）。
- 用户的编辑随时保存，每次提交产生一个新修订号。
- 只有当代理的读集或写集与用户新修改的单元格重叠时，代理的提交才被拒绝；代理只需重读被改的单元格再写。界面在代理重读时显示提示"表格刚被你修改，代理正在重新读取"。
- 读过该区域的代理在下一步收到通知（"用户修改了 汇总!B2:B9"），而不是等到写入冲突时才发现。
- 代理写入后，若用户正在编辑的单元格被代理改了，用户未提交的输入不会被静默覆盖：弹出冲突条，显示"你的输入 / 代理的值"，让用户选择保留哪个（保留用户输入即产生一次新的用户编辑）。
- 用户自己的编辑提交（`doc.submit`）也可能被拒（例如恰好与代理刚写入的单元格重叠）：前端撤销本地变更，在该单元格显示冲突条，让用户选择保留谁的值。

### 4.8 界面跟随

- "跟随代理"开关（默认开）：代理读写某文件时，工作台自动打开该文件并滚动到活动区域。
- 以下情况不自动跳转，只在文件标签上闪烁提示：用户正在编辑单元格、用户在 5 秒内手动切换过视图、目标是另一个子代理的活动。

### 4.9 实时协作

- 代理的写入实时出现在工作台：大批量修改按分片逐步显示（带轻微动画），不打断用户当前的选区与滚动位置。
- 在线状态显示其他窗口/设备与各代理正在查看或编辑的区域：每个参与者有颜色与名称（类似协作编辑的光标）。
- 多个客户端同时打开同一会话与工作簿时，看到的修订与状态一致；每个客户端的编辑提交得到各自的确认。

## 5. 代理团队视图

当会话中存在子代理时，侧栏出现"代理团队"：

- 列表/树：每个代理的名称、颜色、角色、状态（运行中/等待消息/等待审批/已完成/已停止/出错）、当前在做什么（最近的工具调用）、消耗的 token。
- 点击代理进入**代理视图**：该代理的完整对话（与主会话同样的消息流组件），输入框直接向该代理发消息（作为用户消息进入它的收件箱）。
- **团队消息流**：代理之间的消息以"内部消息"形式显示（发件人 → 收件人，摘要），默认折叠在主会话消息流里，可在团队视图中查看全部。
- **任务板**（P1）：共享任务的列表、认领人、状态。
- 操作：暂停、继续、停止单个代理；"停止全部子代理"。

## 6. 文件面板

- 工作区文件树：上传、新建文件夹、重命名、移动（拖放）、删除（移入回收站，可恢复）。
- 文件图标区分：表格、CSV、图片、其他；代理本会话创建或修改过的文件带标记。
- **备份**分组：列出本工作区的修改前备份（原文件名、备份时间、由哪个会话产生），可打开查看、另存、替换回原文件、删除。
- 工作区切换器：顶部下拉，列出已登记的工作区；"添加文件夹"（桌面版弹出系统目录选择框）。

## 7. 设置中心

分组（左侧导航 + 顶部搜索）：

| 分组 | 内容 |
| --- | --- |
| 模型 | 模型档案列表（增删改、设为默认、测试连接、能力探测结果与手动覆盖）、订阅账号（登录/退出/刷新）、按用途选模型（P1） |
| 权限 | 默认权限模式、自动批准的 MCP 工具 |
| 运行 | 单轮最大步数、运行中消息默认策略、自动压缩开关与阈值、子代理预算默认值 |
| 技能 | 内置与用户技能列表、启用/禁用、导入、查看正文 |
| 记忆与规则 | 记忆条目管理；全局规则 |
| MCP | 服务器列表、增删改、连接测试、工具列表 |
| 外观 | 主题、字号、布局偏好 |
| 数据 | 数据目录位置、打开数据目录、清理缓存 |
| 关于 | 版本、检查更新、日志目录、许可证 |

设置表单规则【推荐】：每个字段写明"改变什么、取值含义、何时生效"；数值字段带单位与范围（与服务端 schema 一致，由 schema 生成）；保存只提交修改过的字段；需要重启的项在保存前提示。

## 8. 首次引导

1. 欢迎页 → 选择"添加 API 密钥"或"登录 ChatGPT 订阅"。
2. 添加后自动测试连接与能力探测，显示结果（支持工具调用 ✓、视觉 ✓、思考 ✓）。
3. 提供示例工作簿（内置），引导完成一个 3 步任务：读表 → 让代理高亮并确认区域 → 修改并查看变更高亮。
4. 引导可跳过、可在设置中重新打开。

## 9. 状态与错误

| 情况 | 界面 |
| --- | --- |
| 未配置模型 | 输入框上方卡片"还没有可用的模型"，按钮直达设置；仍可浏览文件与表格 |
| 与后端断开 | 顶部细条"正在重新连接…"；恢复后通过同步通道续传 |
| 会话中断（服务重启时正在运行） | 消息流末尾"任务在服务重启时中断"，按钮"继续"（发送 `/resume` 语义的继续请求，见 [04 §8](04-agent-runtime.md#8-中断与恢复)） |
| 模型接口错误 | 错误指引块：分类（认证、额度、限流、网络、上下文超限、模型不支持某功能、服务端错误）、原始错误摘要、下一步按钮 |
| 工具失败 | 卡片显示错误码与说明；代理通常会自行处理 |
