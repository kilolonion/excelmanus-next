# 前端整体重构计划

## 已批准设计与约束

用户批准 01–09 生图设计方向：表格工作台、新会话、文件管理、代理团队、修改审批、模型设置、技能管理、首次引导与移动端。生图为视觉参考，不机械复制：实际流程、状态真实性、可操作性优先。所有页面抽取共享框架，不分别拼装。保留现有后端、权限、修订与数据安全语义。

技术栈：React 19 + Tailwind 4 + 现有 Radix UI + CVA + Lucide 包装层，全部沿用锁定版本。没有理由替换为大型新组件库；新增受许可门禁阻止的依赖必须向用户说明并审批，不绕过门禁。

## 架构

- `components/ui/page-layout.tsx`：PageHeader、PageSection、ListDetailLayout、PageState、SettingsRow 通用页面骨架。
- `components/layout/`：应用框架/工作区导航与设置导航的组合，不依赖具体业务 API。
- 业务组件保留状态和数据操作；通过统一页面骨架、按钮/表单/导航组件组合。
- 主题 token 统一白底、冷灰、深玉绿；深色主题保持可读；状态色与交互色分开。
- 设置九个分页复用 common/page-layout；同类列表、详情、表单、操作区保持一致。
