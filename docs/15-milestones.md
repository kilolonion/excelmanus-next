# 15 里程碑

原则：**每个里程碑结束时都有一个能端到端运行的产品**，只是能力范围不同。每个里程碑的退出条件以 [14](14-quality.md) 中对应的门禁与场景为准。

## M1 可行走的骨架

目标：本机 Web 形态下完成"对话 → 读表 → 回答"。

- 单仓结构、契约包、依赖方向检查、CI 门禁框架。
- 后端：REST、设备令牌、SQLite 与迁移、设置、模型档案（API Key）、会话、**会话日志 + 投影框架 + 同步通道（会话主题，游标续传）**、能力模块接口与 actor 调度。
- 运行时：轮状态机、单代理、只读工具（`read`、`find`、`workbook_read`、`workbook_analyze` 无 `saveTo`）、重试、错误指引。
- 前端：布局、对话面板、工具卡片、只读表格工作台（打开工作簿、选区作为上下文、区域引用可点击）。
- 表格：只读的文档 actor（导入、快照、读取投影、`doc:` 主题的快照获取），为 M2 的编辑打基础。
- 提供商：OpenAI、Anthropic、DeepSeek、一个 OpenAI 兼容国产模型。

**退出条件**：验收场景 1、2、11、22；契约测试、同步通道回放测试在 CI 运行；性能基准首次测量并把 [01 §5.1](01-product.md#51-性能推荐目标值在-m1-结束时用基准测试确认后改为硬性) 的目标值确认为硬性（或调整）。

## M2 编辑闭环

目标：代理与用户都能安全地修改工作簿。

- **活文档**（文档 actor、文档日志、检查点、对象层、区域级冲突、`doc:` 主题与在线状态）、保真编解码、公式计算、修改前备份与回收站。
- 工具：`write`、`edit`、`files`、`workbook_edit`（含图表、条件格式、数据验证）、`workbook_render`、`workbook_export`、`workbook_analyze saveTo`、`present`、`todo`。
- 权限模式与审批（含表格预览层）、`ask_user` 全部题型（含区域确认/选取/修改确认）。
- 工作台编辑（与代理共用写入路径）、代理活动叠加层、变更摘要、变更导航与"修改前的值"、冲突处理。
- 文件面板、备份面板。

**退出条件**：验收场景 3、4、5、6、7、18、24、25；保真语料测试与文档并发模糊测试全量通过。

## M3 可靠性

目标：任何时候关掉、断网、崩溃都不丢东西、不乱写。

- 消息派发三策略、停止、排队撤回、幂等。
- 中断恢复（写前记录、启动恢复、继续）。
- 上下文压缩（历史只追加，除压缩外不改写）。
- `run_script` 与沙箱。
- 模型接口错误分类与重试的完整实现。

**退出条件**：验收场景 8、9、10、12、16、17；跨进程恢复测试与投影重建测试在 CI 运行。

## M4 多代理

- 代理团队、收件箱、五个 `agent_*` 工具、角色与权限、文件租约、预算与失控检测、完成报告。
- 团队视图、代理视图、直接给子代理发消息。
- 多代理的中断恢复。

**退出条件**：验收场景 13、14；多代理的跨进程恢复测试。

## M5 桌面与扩展

- Electron 桌面：自定义协议、`utilityProcess` 后端、离屏截图、`safeStorage`、生命周期、系统通知、打包、签名、自动更新、`--self-test`。
- ChatGPT/Codex 订阅登录。
- 技能（内置 9 个 + 导入）、记忆、规则、MCP。
- 其余提供商预设、能力探测、models.dev 快照。

**退出条件**：验收场景 19、20、21、23；安装包自检在仓库外的 macOS 与 Windows 上通过。

## M6 打磨与发布 v1

- 首次引导与示例工作簿、设置中心完善、深色模式（P1）、快捷键、空状态与错误文案。
- P1 功能按剩余时间取舍（多工作簿标签、并排对比、共享任务板、工作区说明文件等）。
- 真实模型评测集（40 个任务、3 个模型）首次完整运行并达到目标。
- 文档：用户帮助（可复用 `excelmanus-guide` 技能内容）、隐私说明。

**退出条件**：[14 §5](14-quality.md#5-端到端验收场景硬性v1-发布前全部通过) 全部 25 个场景通过并有记录；性能基准达标；无未关闭的 P0 缺陷。
