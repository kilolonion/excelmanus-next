## 2. v1 发布

1. 补齐 [backlog](backlog.md) 中的 P0 功能缺口，P1 按时间取舍。
2. 把新前端实际跑一遍，修掉阻断主流程的问题。
3. CI 自动检查通过，按 [14 §3](14-quality.md#3-发布前冒烟清单) 的冒烟清单走通。
4. 以开源形式发布：GitHub 源码加未签名的桌面 zip 包。签名、公证和自动更新等有证书后再做。
