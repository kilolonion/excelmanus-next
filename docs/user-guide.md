# ExcelManus 使用帮助

ExcelManus 帮你处理工作区中的表格与文件。可用功能取决于当前模型、已启用模块和文件中的特性；遇到不支持的对象或计算，界面与工具会说明限制。

## 开始一个任务

在工作区选择文件，打开工作表并选中相关区域，再描述要得到什么结果。例如“按地区汇总本月销售额，放到新工作表，并核对总额”。给出重要的期间、单位、匹配键或保留规则，能减少歧义。

简单的改单元格、解释公式或查合计可以直接提出。报表、清洗、对账、布局和图片录入可获得任务技能指导；不必先选择技能。需要显式使用某个技能时，可输入 /技能名 加任务要求。

## 设置入口

侧栏按“工作区 → 会话”组织聊天：展开工作区可以看到它的会话，点击会话自动进入所属工作区。分组旁的加号会在该工作区新建；顶部“新建会话”沿用当前聊天的工作区。历史较多时点击“展开显示”，搜索会保留匹配会话的工作区归属。

切到“文件”页查看当前聊天所属工作区的文件，也可以从工作区分组菜单直接进入该区文件。没有自选文件夹时可直接使用默认工作区；“添加文件夹”用于登记其他目录。刷新会恢复工作区与会话，删除本区最后一条会话会留下新的空白落点，工作区文件不会随会话删除。

侧栏底部“设置”中可以管理：

- 模型：先「添加供应商」，配置共享接口地址、Key 和请求头，再在供应商卡片中「添加模型」。组内模型共用连接与拉取的目录，可搜索选择或手填模型 ID。
  - 模型高级选项设置上下文、最大输出、图片输入、工具和思考能力；留空或重置为自动时采用目录默认值。手动能力设置不是实际探测结果。
  - 更新供应商连接会影响该组全部模型的后续请求。刷新目录失败会保留旧列表；修改连接后需要重新拉取目录和探测能力。
  - 删除供应商前先移走或删除其模型；被子代理、压缩用途或未关闭代理使用的模型需先解除绑定。
  - 从旧配置升级时保留模型 ID、默认及用途绑定，启动前自动保存数据库快照。此版本协议为 v4，升级后刷新浏览器。
- 订阅账号：连接支持的订阅账号；接入限制以登录结果为准。
- 权限与运行：默认权限、子代理模型与并发、上下文压缩、网络代理、记忆注入等运行设置。
- 规则：保存你希望代理遵守的要求。修改后会在后续消息边界告知代理。
- 记忆：管理偏好、业务口径和经验；可编辑或删除。
- 技能：查看、启用或导入任务方法。技能不会增加工具，也不会改变权限。
- MCP：连接外部工具服务，查看连接状态与批准设置。本机命令依赖需要自行具备。
- 工作区与备份：管理工作区、修改前备份和回收站。
- 外观与关于：主题、字号、快捷键、版本、本帮助和重新打开引导。

## 修改与审批

confirm 模式下写入也需要批准；standard 模式下普通写入自动执行，删除和外部调用需要批准；auto 模式自动处理通常的工具审批。脚本的发布清单与审批以当次界面为准。

已有文件在会话内首次修改前自动备份。备份是轻量保护，不等于任意修订历史或通用撤销；需要恢复时在备份页面选择替换，当前文件也会先备份。

用户编辑与代理修改进入同一文档写入路径。区域发生冲突时，代理需重读后处理，不能用过时内容覆盖你的编辑。

也可以直接在工作台里编辑：顶部的格式工具栏提供字体、字号、加粗 / 斜体 / 下划线 / 删除线、文字与填充颜色、对齐与换行、边框、合并单元格和常用数字格式，宽度不够时收进“⋯”。表格右侧和下方留有空白行列，可以继续往外输入。CSV 只保存数据，需要格式请先另存为 xlsx。“跟随代理”和表格标记的显示开关在工具栏右侧的“视图选项”中。

边框：打开“边框”，先选择线型（含粗细、虚线和双线）与颜色，再选择所有框线、外框、内框或指定边。支持 3 位或 6 位十六进制自定义颜色；“无框线”清除选区边框。

格式刷：先选来源区域，再点击刷子并选择目标区域；下拉菜单可开启连续格式刷，按 Esc 结束。只复制格式，不复制值、公式或合并范围，支持撤销。单次来源和目标最多 20,000 格。

表对象：选中区域后点击“表管理”，可创建 Excel 表、调整名称 / 范围 / 列名、选择条纹样式及表头、筛选、汇总行。汇总行沿用最后一行内容，不自动覆盖数据。支持 `SUM(表名[列名])` 等结构化引用；改名同步更新单元格公式，转换为普通区域保留数据并改写引用，操作可撤销、保存后重开。含扩展或复杂筛选的原有表保留原始部件，暂不进入编辑器。

定义名：点击“名称管理器”，新增、修改或删除工作簿 / 工作表作用域的名称，填写引用区域、常量或公式。名称可直接用于单元格公式，重命名会同步更新引擎识别的公式引用。单一区域引用支持定位，删除名称不会删除单元格，但依赖它的公式可能显示 #NAME?；支持撤销和保存后重开。

数组公式：点击“数组公式”管理当前工作表的数组。固定数组按选定区域整块新增、修改或清除，不能只改其中一个结果格；单块最多 20,000 格。动态数组只编辑左上角公式，由引擎自动溢出；遇到非空单元格时显示 #SPILL!，不会覆盖阻挡内容。管理器显示实际溢出范围，支持定位、撤销、保存及重开；缩小范围会清除旧结果并保留单元格格式。仅支持引擎已实现的公式函数，超出支持范围的原有数组仍保留并保护。

条件格式：点击调色盘图标，管理当前工作表的规则。支持新增、修改和删除双色 / 三色色阶、标准渐变数据条及常用 3 / 4 / 5 级图标集；可编辑应用区域、阈值、颜色、图标顺序和数值显示。多个区域用空格分隔。规则在表格里实时显示，随工作簿保存，支持撤销。暂不编辑 Excel 扩展数据条、自定义图标及未识别的规则，这些内容仍原样保留在文件中。

代理提交修改后，表格会短暂亮起绿色边框，并显示“刚刚修改”的区域数与修订号。这是改动提示，不是单元格格式：6 秒内会自动淡出，也可以点击“清除高亮”立即移除。重复修改时提示以最新提交为准；高亮消失后，仍可通过下方“本轮改动 / 本会话改动”导航定位并查看变更。

## 复杂任务与结果

批量任务可以顺序执行、用沙箱脚本或拆给代理团队。最终结果应指出每个输入的状态、输出位置和核验结果。团队成员完成或文件生成，不代表数据已核验。

公式写入成功与公式结果计算成功不同。函数不支持、缓存缺失或外部引用无法解析时，代理应说明未验证部分。

图片录入需要模型视觉能力；截图对照还需要可用渲染端。本机 Web 需要连接的页面参与渲染，桌面可使用离屏渲染；渲染结果可能不覆盖全部 Excel 对象，限制以结果说明为准。

## 文件与安全边界

文件操作限定在工作区，内部 .excelmanus/ 目录对代理不可见。沙箱脚本不能执行任意 shell、访问网络或工作区外文件。工具对不能保留的文件特性会拒绝修改并说明，不能以静默丢失换取写入成功。

不要把 API Key 粘贴到对话、规则或技能正文中；凭据在模型和连接设置中管理，读取时显示掩码。


## 已有数据透视表与切片器

可以读取已有透视表、源工作表和范围、缓存及切片器关联，并区分原始刷新属性、缺省值和当前修订待保存的刷新标记。overview 中 unsupported 是保留部件数量，不是对象数量。

修改本地工作表源数据后，可将唯一可识别的矩形区域缓存标记为下次由 Excel 打开时刷新。此操作影响共享该缓存的所有透视表，但不会当场刷新、重写缓存记录或透视显示值，不等于报表已经更新。下载保留原透视对象和切片器；浏览器只显示原保存的单元格结果，不提供切片器交互。

仅支持已有本地 worksheet + 矩形 ref 来源。不支持外部/OLAP/命名来源、歧义关系、禁用刷新的缓存、修改源定义、直接清除标记，或与源结构变化同批执行。合法修订撤销可恢复原始缺省状态。

## 图表、规则、图片与形状

可以让代理“按地区汇总并插入可在 Excel 编辑的柱状图”“把空值标黄”“限制输入范围”“调整行高列宽、隐藏明细、设置分组”。工作台可显示柱形、条形、折线、面积、散点、饼图、圆环和柱线组合图，并随当前单元格值更新；嵌入的 PNG/JPEG/GIF 显示原始图片。对象随表格滚动和缩放，在画布内裁切。下载的 xlsx 继续保存原生图表或原始图片。预览采用统一样式，不保证复现 Excel 的所有自定义样式或复杂系列布局；未识别对象仍原样保存在文件中。

图片可从工作区新增到工作簿，或提取已有图片交给支持视觉的模型。支持 PNG/JPEG/GIF，单图最多10 MB。若文件含无法安全修改的对象，应用会拒绝相关操作，原文件保持不变。

可以让代理新增、移动、缩放或删除图片，以及简单的矩形、椭圆和右箭头形状。移动或缩放已有对象时保留图片内容和形状原文字样式；锚点含单元格地址与像素偏移。分组、连接器、旋转、复杂填充或富文本形状仅保留，不能编辑。读取对象时会列出保留的复杂绘图与限制，不能因截图未显示而判断原件没有对象。形状预览只近似基本填色、边线和纯文本，字体、对齐与换行不保证复现 Excel。

## 分析、对账与校验

可要求跨文件或跨表关联汇总、按唯一业务键对账、检查必填/重复/取值范围/外键/合计和公式错误。给出表头、匹配键、日期口径与数值容差；重复业务键会被明确报告，不能假装一一对应。

大查询有时间和规模限制，超时会结束独立查询进程，不让整个应用卡死。依赖图只能静态分析常见引用，INDIRECT/OFFSET、外部工作簿和复杂定义名会说明覆盖限制。

## 文件与诊断

文件页可以进入目录、上传到当前目录、新建文件夹、重命名和移入回收站。打开中的单个工作簿可重命名或移动，已有修订与备份继续关联；包含活文档的整目录移动和批量移动仍受保护。删除前需关闭工作簿。删除会请求确认，备份/回收站仍可按原流程恢复。

设置的关于页可下载诊断 JSON，只包含版本、日志类型、错误代码、耗时和 token 等允许的元数据，不包含模型密钥、完整提示词或文件内容。发送给他人前仍建议自行检查。

如提示前后端版本不一致，请刷新网页或升级桌面端。此时会停止同步，避免用不兼容的编辑协议修改文件。

工作表支持复制、移动、隐藏（至少保留一张可见表）；支持公式填充、自动估算行列尺寸、枚举/空值筛选和单格超链接。带复杂对象或规则的工作表复制会拒绝而不是丢弃对象。自动尺寸不保证与 Excel 字体测量完全一致。

### 行列分组与隐藏

分组层级、隐藏状态和汇总行列的折叠标记分别保存，取消隐藏不等于分组已完整展开。可要求代理保留嵌套层级、展开指定明细并清除对应汇总标记，同时保留其他独立隐藏行列；只清折叠标记不会自动显示明细。下载件保存这些状态，撤销与重新打开也按工作簿状态处理。

在「视图选项 → 分组与隐藏状态（只读）」可查看当前表的行列区间、层级、隐藏与折叠标记，以及文件指定或缺省的汇总方向。相同状态的连续区间仅为摘要，不代表组边界。界面没有原生 ± 分组控件，文件要求显示分组符号也不代表浏览器已提供该交互。

普通工作表支持整组之外插删行，原记录的公式、行高、隐藏、层级与折叠标记随行平移，列状态保留。新插入行为空白、可见、未分组。组内插入、删除组成员或汇总行，以及带分组的列插删暂不支持；表新增、重命名或复制与行列插删也不在同一批执行。含打印区域、重复标题、分页、复杂对象或尚不能安全平移引用的工作簿仍会明确拒绝，不会通过取消分组绕过保护。

### 表格右键操作

先选择连续区域，再右键复制、粘贴或排序。排序窗口可选择列、升降序以及首行是否为表头；请包含需要一起移动的全部列。XLSX 的「筛选数据」可按列勾选保留值，再次打开会保留条件，其他列条件不变；「移除筛选」恢复显示。筛选与排序支持撤销。CSV/TSV 仅保存数据，提供仅值粘贴和排序；筛选及格式请先另存为 XLSX。

### 文件排序

文件面板默认按「最近使用」排列，打开过的表格按最近打开时间靠前，未打开过的文件靠后。可切换最近修改、文件名称或本对话改动；列表和文件夹视图共用排序，刷新页面后仍保留选择。文件夹视图始终将目录放在文件前面。

### 附件上传重试

对话输入框中的图片或文件上传失败后，错误旁会显示「重试」。浏览器会在本地保存尚未上传成功的原文件，重试仍上传到最初的工作区和目录，不会重复添加附件。切换对话不会把上传结果放进另一个对话；移除附件后，迟到的上传结果也不会恢复该附件。刷新或关闭标签页后，重新进入同一对话可恢复未完成的附件，点击「重试」继续上传，不会自动重传。浏览器存储不可用、被清理或容量不足时会提示重新添加；成功上传或移除后清理本地原文件。遇到同名冲突，请先更换已有文件名或重新选择另一文件，再重试。

### 旧格式导入

点击工作区中的 .xls / .xlsb，或在打开表格窗口上传这两类文件，确认转换说明后会生成带时间戳的新 .xlsx 并打开。保留原文件，不覆盖已有目标。保留可解析的值、公式、数字格式、合并区域和行列尺寸；字体、边框、填充和高级对象不保证保留。宏不会进入新 .xlsx。加密或无法解析的文件需先在 Excel 中解密或另存。最大 50 MB。

### 缩放、图片删除与批注

工作台右下角可输入百分比，按回车或移出焦点提交；Escape 取消，非法值恢复原比例。图片悬停时显示删除按钮，确认后写回工作簿，可在修订历史撤销。选中单元格后，右键「批注 / 备注…」可新增、修改或删除传统 Excel 备注；有备注的单元格显示红色角标，悬停查看文字。新式线程批注及回复暂不编辑，原文件内容保留。

- 断线时没有发出的表格修改可在恢复连接后点「重新发送」。若修改已发出但确认回包前断线，会提示「保存结果待确认」：先点「刷新核对」，对照服务端内容和修订历史确认后关闭提示，避免重复插行等操作。
- 当前浏览器会按工作区、文档和单元格保存尚未提交的单元格输入、被覆盖的输入草稿和待确认提交。整页刷新或关闭标签页后重新打开同一文档，会显示恢复提示；先核对当前值，再选择写回或放弃。已发出的操作不会因刷新自动重放。处理完后清除对应草稿；浏览器存储不可用或已满时会明确提示。旧标签页处理完自己的输入不会清掉其他标签页的新草稿；恢复不会自动写回，即使当前值已变化仍需手动选择。清除站点数据或换浏览器后无法恢复。
- 对话文字和附件引用按会话、代理保存在当前浏览器，关闭标签页后重开可恢复。多标签页不会把正在编辑的输入替换掉；发送成功只清除对应草稿，其他标签页新增的附件不会一起丢失。清除站点数据或更换浏览器后无法恢复。

### PDF / 打印导出

工作簿内的打印设置与浏览器 PDF 预览是两层功能。助手可以读取工作簿打印区域、重复标题、分页、页面和页边距、页眉页脚原始字段；可以设置单矩形打印区域、重复标题行、手动行列分页、纸张方向及适合页宽/页高、奇数页页眉页脚，并随 XLSX 保存。未指定设置保留，明确清除才删除；修改标题行不删除已有标题列。页码、总页数、文件名和表名保留为动态字段，不改成静态正文。复杂打印区域、打印机驱动和富排版不在写入范围内。

工作台顶部「导出 PDF / 打印」可选择工作簿单矩形打印区域、当前工作表或当前选区；初始采用可用的工作簿区域和 A4 横竖方向，不支持的源配置会提示。范围与方向切换仅影响本次预览，不写回工作簿。预览自动适宽、页边距固定 12mm，未采用源缩放/页边距，也未投影重复标题、手动分页和页眉页脚；可展开查看源设置摘要，但不能以此预览证明 XLSX 打印保真。

打开浏览器打印预览后，在目标中选择「另存为 PDF」。中文文字可复制；支持常用文字样式、数字显示、行高列宽及合并区域，隐藏行列不导出。范围会扩展至相交合并单元格，超过 20,000 格时需缩小选区。包含工作台支持的图表、嵌入图片、条件格式色阶/数据条/图标集及边框线型和颜色，按 A4 页面裁剪分段；图片加载失败会提示，避免静默漏印。引用区外数据的图表会略去。浏览器禁止打印时无法完成最后保存。

### 备份只读预览

在文件信息的备份列表或「设置 → 工作区」备份/回收站列表中，点击眼睛图标。XLSX/XLSM/CSV/TSV 可切换工作表、按 80 行或 30 列翻页；展示缓存公式值，不重新计算。常见图片和 UTF-8 文本也可直接查看，长文本仅显示前 100,000 字符。表格预览保留基础布局，但不完整渲染边框、条件格式和浮动对象。旧版 XLS/XLSB、PDF 等格式请下载查看。预览不创建活文档，不恢复、不改动当前文件。

### 含活文档的文件夹移动

文件夹中有已打开或登记的工作簿时，也可以重命名或整体移动。系统先写回其中的待保存修改，再一起更新文件路径；打开标签、文档身份、修订历史和备份来源继续跟随。目标已存在或试图把文件夹移入自身时拒绝操作，不覆盖其他文件。

### 批量文件操作

批量拖动多个文件时会一次提交；目标冲突或任一操作失败会回滚整批，打开的工作簿标签只在成功后一起更新。活文档移动可与普通文件复制、新建目录、删除等同批进行；删除活文档及路径互相重叠的批次仍会拒绝。执行前暂存原内容，需要相应磁盘空间。中断后根据原内容与预期结果恢复；若发现额外外部修改或不完整复制，保留恢复副本并明确报错，不猜测覆盖。

## 对比后合并

在工作台或文件菜单打开「与另一个表格对比」，选右侧工作簿，勾选差异后点「右侧 → 合并到左侧」。交换左右可反向操作；默认不选择任何内容。合并仅写入选中的值与公式，保留目标样式，不复制图片、图表或其他对象；源工作簿不变。右侧为空会清空左侧对应内容，右侧独有的工作表会新建并仅填入选中格，左侧独有的表不会自动删除。CSV 无法增加工作表，需先另存为 XLSX。

确认前显示目标、数量与新增工作表。双方在预览后有变化会拒绝提交，需重新对比；整次合并是一条用户修订，可在「修订历史」撤销。公式在目标上下文重新计算，缓存结果可能与来源不同。每次最多列出和合并 2000 处差异，未列出的不受影响，完成后可继续对比；富文本和未展开的共享公式暂不合并，会明确报错。

### ChatGPT 订阅连接

在设置 → 模型与连接 → 订阅账号中连接 ChatGPT。公网或局域网访问默认使用设备码；在官方登录页完成账号授权后返回本页，账号和模型会自动出现。设备码登录需在 ChatGPT 安全设置或工作区权限中启用。localhost / 桌面版保留浏览器回调，并提供设备码备选；不要在远程服务器上依赖访问者本机的 localhost 回调。授权只连接订阅模型，不改变工作台的登录方式。

订阅授权进行中关闭设置或刷新页面后，重新打开订阅账号面板会继续查询原登录；仅在浏览器保存短期登录编号，不保存订阅令牌。取消、完成或超过 15 分钟后清除编号；服务重启导致登录编号失效时需重新发起。查询网络错误可以点击“重新检查连接状态”。

### 线程批注

XLSX/XLSM 工作台顶部「批注面板」打开右侧讨论列表。选中单元格后「新建批注」，填写显示署名和内容；同一单元格已有未解决讨论时自动回复该讨论。可回复、解决、显示已解决讨论及重新打开，点击工作表与单元格地址定位。署名是文件内显示名称，不代表账号认证，不发送通知。

批注随活文档修订一起保存，可从「修订历史」撤销；原文件中的作者、时间、回复关系及未修改扩展内容保留。新批注写入 Excel 线程批注结构，下载后仍在文件内。传统备注沿用右键菜单的增改删。为防止锚点错位，含线程批注的工作表暂不接受行列结构移动、排序或复制工作表；普通单元格内容编辑不受影响。暂不提供线程原文编辑或 @通知。
