## 4. 一代功能待后端适配

一代界面里有、二代后端还没有的功能，界面上已经去掉（不留空壳）。需要时先在 `protocol` 定义，再补后端，最后接回界面。

### 4.1 已接回界面（2026-10-11）

下列后端能力已接进 Web 界面：修订历史与撤销（工作台工具栏「修订历史」、`/undo`）；表格并排对比（工作台工具栏、文件菜单与文件信息里的「与另一个表格对比」，只读，「合并」仍待做）；新建空文件（文件面板「更多 → 新建文件」、文件夹菜单）；文件信息里的来源与修改历史、最近打开时间；输入框的编辑 / 问答 / 计划模式；回复点赞/点踩；会话「导出 → 完整记录 .json」；代理团队面板「只停子代理」；压缩进行中提示；设置「自动生成对话标题」；「代理正在重新读取」提示条（`context.notice doc.edited`）；服务重启中断后的「继续」提示。尚未接：按 `openedAt` 排序的「最近使用」列表。

以下为当时的后端接口说明，保留备查。

契约见 [11 §1「一代功能的后端适配」](11-api-contract.md#一代功能的后端适配2026-10-11)。

- **修订撤销**：`GET /workspaces/{id}/docs/{docId}/revs` 列修订（新到旧，标注 `reverts`/`revertedBy`）；`POST …/revs/{rev}/undo` 撤销一次修订，之后有修订改到同一区域或表结构时 409。可接撤销面板与 `/undo`。
- **工作簿并排对比**：`POST /workspaces/{id}/docs/compare`（按表名配对、逐格比较值与公式）。「合并」仍待做：可在对比结果上让用户勾选后经 `doc.submit` 写入。
- **文件**：`POST /workspaces/{id}/files/new` 新建空的 .xlsx/.csv/.txt/.md；`GET /workspaces/{id}/files/history?path=` 来源与事件历史（新建、每次修订的来源/会话/区域、备份、删除）；文件列表项带 `openedAt`，可按最近使用排序。
- **对话**：`SendMessageBody.chatMode`（`ask` 只读问答 / `plan` 计划模式，两者都禁止写入）；首轮完成后自动生成会话标题（设置 `autoTitle`，`session.updated.auto = true`）；`POST /sessions/{id}/feedback` 点赞/点踩（`feedback.given` 记录）；`GET /sessions/{id}/export/json` 会话 JSON 导出。默认派发模式设置原本就有（`defaultDispatchMode`）。
- **代理团队**：`POST /sessions/{id}/stop-all` 带 `{ scope: "subagents" }` 只停子代理；压缩进行中推送 `compaction.progress` 应用事件（阈值为上下文窗口 80%，`usage.updated.context` 已带占用与窗口）。给子代理追加指令（向该代理发消息）、回答子代理提问（`POST /questions/{id}`）、子代理运行结果（`inbox.sent` 的 `kind: "report"`）后端原本就支持。

## 5. 新发现的问题（2026-10-11）

- 交付的源码原本没有 git。现已在本地初始化，基线提交是 2026-10-10 交付的原样（原仓库提交 575912c 的历史不在其中）。还没推到 GitHub，CI 从未在这份代码上运行过。
- 不少历史文档引用了 `.agents/`、`.claude/` 下的文件（日志、审计报告、`launch.json`），这两个目录被 `.gitignore` 忽略，别人拿到仓库时都是死链。新文档不再引用；历史验收记录保持原样。
- `docs/design/m6a-stitch-alignment.md` 和 `acceptance/m6a-frontend.md` §5 的状态已经过时（例如「presence 未做」「右键问代理未实现」，代码里都已实现）。台账已标为归档。
- `pnpm check:all` 有约 630 条 Biome 警告（不阻断，多数来自一代前端的 a11y 与依赖数组规则）。Web 构建中 Univer 包 11.6 MB（gzip 后 2.8 MB），有大 chunk 警告。
- Univer 公式计算跑在主线程（`packages/modules/workbook/src/engine.ts`），大工作簿写回时可能卡顿。
- 浏览器复核脚本（`packages/web/test/fixtures/*-browser.mjs`）需要从外部提供 Playwright（`PLAYWRIGHT_MODULE`），它不在依赖里。
- CI 没装 LibreOffice，相关测试在 CI 中会跳过"实际打开文件"的校验；本机装了 LibreOffice 时会自动执行。
- 交付目录外层的 `frontend-changes.patch` 已经合入源码，不需要再应用。
- Sealos DevBox：最后记录的状态是 Running，测试服务对公网开放。需要确认是否暂停，避免持续计费。
- CSV 文件里按 Ctrl/⌘+B 等格式快捷键仍会在本地改样式，提交后被服务端拒绝并弹出冲突条；可以在 CSV 下屏蔽这些快捷键。
- 打开工作簿时控制台有 React「synchronously unmount a root」警告（Univer 实例在渲染中被重建），不影响功能。
- 刷新页面后区域确认卡的「确认」按钮是禁用的（提示先打开表格），要先点区域标签打开表格；可以考虑点「确认」时自动打开。
- 工作簿并发模糊测试在较慢机器上约 60 秒，超时上限已放宽到 180 秒。
