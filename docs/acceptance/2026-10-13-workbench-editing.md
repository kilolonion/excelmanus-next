# 工作台编辑与断连恢复验收（2026-10-13）

## 范围与结果

- 缩放输入：替换 Univer 内置输入，支持百分号、Enter/失焦提交、Escape 取消和非法值回退；输入框、滑块与画布一致。公网浏览器验证 80%、125%、非法输入及重置 100%。
- 图片删除：经过活文档 mutation 和检查点写回。公网 QA 文件删除后刷新保持删除，修订撤销并重开后恢复图片。原始 DrawingML 锚点保留为惰性 XML 注释以支持无损撤销，因此删除不是敏感图片字节的彻底清除。
- 传统 Excel 批注/备注：右键新增、修改、删除；作者、中文多行、特殊字符和角标；每一步均在公网页面操作并刷新回读。OOXML comments/VML 增改删回归通过。多人回复式线程批注没有实现。
- 断连恢复：真实 HTTP + TCP/WebSocket 集成测试使用独立 loopback 测试服务，验证连接终止、取票失败后重试、游标重订阅、离线输入保留、不自动重发和显式重发一次。
- 已发送但未确认时断连：修复永久“提交中”。状态变为“保存结果待确认”，保留原输入，提供刷新核对；不自动重发可能已执行的结构操作。真实 WebSocket 丢失确认路径、状态机和工作簿 store 回归通过。
