## 已知问题与后续

- **三平台**：全部验证只在 macOS arm64；x64 / Windows x64 未测（ADR 0001 跟进项）。CI 同跑 `pnpm test`，但沙箱在 Linux x64 的结果未实测。
- **场景 8 / 10 / 12 的"部分"项**：浏览器实机（刷新一致性）、真实模型的"先重新读取"与"记得目标"行为未验证；`uncertain` 卡片状态只经 `reduce.test.ts` 断言。
- **ADR 0009（2026-09-30 修订）**：审批已恢复为发布时——`dryRun` 预演 + `publishPlan`/`planHash` 进审批卡片、批准后按内存计划发布、重启重跑核 `planHash`；写后读改为明确 `UNSUPPORTED_FEATURE` 报错（原"静默读已发布"已移除）。仍未做：脚本内 overlay 读取（读到自己未发布的写入）。
- **run_script 范围**：reader 只读模式已在 M4 补齐（`wb.edit`/`files.writeText` 对 reader 抛 `INVALID_ARGUMENT`，见 `m4.md`）；`wb.export`/`files.manage` 不在 SDK 范围；QuickJS 强杀时打印 `JS_FreeRuntime` 断言噪音（ADR 0001 已知）。
- **摘要模型**：复用本代理 ResolvedModel（09 的用途分配无配置设施）；自动压缩的 UI 开关未做（`autoCompact` dep 已支持）；token 估算为字符数/4。
- **lint**：61 warnings + 3 infos 为既有告警级（含 `spikes/*` 与 `noNonNullAssertion`），未处理，是否收口由负责人决定。
- **迁移**：具名迁移 + 旧库探测引导只适配线性追加历史；部分对象存在的不一致库拒绝启动（ADR 0004 修订）。
- **未 commit**：M3 全部改动与并行批次的 M2/M4 改动共存于工作树。
