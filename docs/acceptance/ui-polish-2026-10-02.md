# UI、动效、组件与响应布局打磨

日期：2026-10-02（Asia/Shanghai）。范围：M6a 的视觉与交互打磨，依据 02、16 的开放视觉范围。该记录不将 M6a/M6b 其余验收项标记为完成。

## 改动与取舍

- 导航侧栏与纸面主区域有清楚的层次；统一温暖中性色、间距、圆角、描边与浅/深色 token。新建会话为主要操作，搜索、工作区树和列表留出稳定的间距。
- 首页重新组织品牌、标题、任务卡与真实工作区/模型状态；任务卡按面板宽度变为三列或两列，窄列采用横向紧凑卡。首次引导的三个步骤使用独立表面和明确的步骤状态。
- 对话工具卡减轻阴影；用户消息与助手正文有轻重差异。输入区统一焦点反馈、附件/上下文和操作行；运行中的发送策略与停止可换行，所有按钮保持可见。
- 文档头去掉重复的选区徽标，保留公式栏、输入上下文、文档状态与问代理。待处理区独立滚动，短窗口的审批操作固定在可见底部。
- 设置中心统一分类、内容页标题、分区、卡片与表单密度；分页切换回到页面顶部，Esc 关闭后归还焦点。共享 Dialog 同样支持由状态打开的弹窗归还焦点。
- 使用 150–320ms 的悬停、淡入、展开、焦点和关闭反馈；减少动效同时禁用悬停位移。消息正文没有逐 token 入场动画，保持历史阅读控制。
- 工作簿与设置入口延迟加载，React/组件/状态位于共享包，构建产物没有入口与工作簿之间的循环引用。没有修改依赖、许可证或依赖方向门禁。
- 空白任务页从顶部浏览，真正消息沿用原滚动契约。拖动分隔条补充指针取消/失去捕获的清理。
- 工作台重新挂载时核对快照修订；缓存落后则先读取权威快照，不重建正在编辑的工作台。远端回放队列遇到已卸载桥接时补取快照，旧文档刷新不影响后来打开的文档。变更对比的新值从当前服务端快照读取。

采用草案的温暖中性色、轻边框、编辑工作室排版和语义色；侧栏、任务卡和工作台尺寸按真实视口调整。没有按草案添加终端、分享、多工作簿、语音或其他未定义能力。

## 环境与边界

- macOS、Node 24.1.0、pnpm 10.11.0、Playwright 1.63.0 Chromium（无头）。使用 Vite **生产构建**，不是静态示意页面。
- 后端使用 `packages/server/test/fixtures/ui-preview-server.ts`，真实 HTTP、WebSocket、SQLite、文档 actor、审批和工具执行；只替代模型输出。独立 `/tmp/excelmanus-ui-*` 目录与示例 CSV，不使用真实用户数据目录。
- 最终示例 CSV 为 25 行、5 列，包含 `月份,区域,负责人,销售额,原备注`；固定模型脚本读取 A1:D25、请求区域确认、写入 E1:E4，将第五列表头改为“备注”。这里只验证 UI/服务端状态与交互，不验证真实模型效果。
- 页面复核脚本：`packages/web/test/fixtures/ui-polish-browser.mjs`；历史阅读回归复用 `chat-scroll-browser.mjs` 与 `chat-scroll-server.ts`。

## 已知边界

- 768px 为文档预留布局检查，不是手机实机验收或新支持承诺；v1 最小宽度仍为 1024px。
- 页面复核仅使用假模型，不证明真实提供商、订阅登录或模型任务质量。
- `change.summary` 在当前前端会产生“未知记录类型”警告并忽略，遵守既有未知记录策略。工具结果与文档同步仍驱动本轮变更展示；这项警告不作为已修复项。
- 早期四列 CSV 复核暴露了 E 列超出现有网格后的区域提示；本轮不修改工作簿范围契约，最终流程使用五列样本，越界写入不能据此宣称通过。随后发现的“修订已更新、重新挂载仍取旧快照”和变更对比新值过时问题已在前端修复，并补入实际提交值和标签切换验收。
- 本轮没有更新桌面安装包、签名或自动更新验收。

## 复跑

先在独立临时数据目录的 `workspace/` 放入上述示例 CSV，再启动真实预览服务：

```sh
node packages/server/test/fixtures/ui-preview-server.ts <dataDir> <port> packages/web/dist
PLAYWRIGHT_MODULE=<Playwright index.mjs> node packages/web/test/fixtures/ui-polish-browser.mjs http://127.0.0.1:<port> docs/acceptance/ui-polish-2026-10-02
```

脚本首次运行会在该隔离服务中通过设置界面配置验收模型。需要检查写入修订时使用新的临时数据目录，避免相同 E1:E4 再次写入成为无变化操作。格式门禁前格式化复核生成的 JSON 文件。
