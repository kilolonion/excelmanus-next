# M6a 草图对齐清单（stitch 工作台 / 设置中心）

> **已归档（2026-10-11）**：此台账不再维护，下方维护规则不再适用，部分状态已过时（如 presence、右键「问代理」现已实现）。待办统一记在 [backlog](../backlog.md)。

本文件是 M6a 前端收口中"对照 `stitch/` 草图优化与补齐"的**唯一进度台账**。草图只是参考（[16 §1](../16-design-reference.md#1-定位与使用方式)），条目来自 2026-10-01 的逐项对比；取舍理由写在条目里，实现证据写进 [acceptance/m6a-frontend.md](../acceptance/m6a-frontend.md)。

## 维护规则

- 每项有固定编号，**不复用、不重排**；废弃的项改状态为「不做」并写原因。
- 状态：`待做` → `进行中` → `已完成`（必须填证据：实测记录、截图或测试）；`阻塞`（写清缺什么）；`不做`。
- 「已完成」以真实页面复核为准（真实后端 + 假模型，见 acceptance §3），没有证据不得标记。
- 新发现的差距追加到对应分组末尾；影响用户可见行为且文档未定义的，先记 [附录 C](../appendix-c-open-questions.md)。
- 每次改动更新「更新记录」一行：日期、编号、结果。
