## 3. 已知风险

| 风险 | 缓解 |
| --- | --- |
| xlsx 保真是长尾问题，语料之外的文件仍可能出问题 | 不认识就拒绝写入；允许用户上报问题文件（脱敏后）扩充语料 |
| 订阅接口非公开，可能随时变化 | 隔离在 `SubscriptionProvider` 之后；失败时明确提示并建议使用 API Key |
| AI SDK 大版本升级带来破坏性变化 | 模型网关隔离；锁定版本；升级时跑提供商回放测试 |
| 多代理增加成本与不可预测性 | 预算上限、失控检测、默认并发 4、用户随时可停止 |
| 从零重写周期长，期间旧版无人维护 | M1 起每个里程碑都是可运行产品；必要时可提前小范围试用 |
| 与 Univer 内部格式（mutation、快照）耦合 | 前后端锁定同一精确版本；文档日志记录引擎版本；Univer 升级时必跑操作回放一致性测试；备选见 [07 §2.2](07-workbook-engine.md#22-备选) |
