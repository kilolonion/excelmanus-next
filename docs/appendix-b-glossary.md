# 附录 B 术语表

| 术语 | 含义 |
| --- | --- |
| 工作区 Workspace | 登记给产品的一个本机文件夹；代理只能访问当前会话绑定的工作区 |
| 会话 Session | 用户可见的一次对话，绑定一个工作区，包含一个代理团队 |
| 代理 Agent | 执行者；主代理与用户直接对话，子代理由代理派生 |
| 团队 Team | 同一会话中的全部代理 |
| 角色 Role | 代理的工具与权限模板：main / lead / worker / reader |
| 轮 Turn | 代理从收到输入到给出最终回复（或暂停/中断/失败）的过程 |
| 步 Step | 一次模型调用及其产生的全部工具调用 |
| 步骤边界 | 一步结束、下一步开始之前；收件箱消息在此注入 |
| 对话记录 Transcript | 代理的消息序列，模型上下文的来源；是会话日志的投影（`agent_context`） |
| 收件箱 Inbox | 代理的待处理消息队列：用户消息、代理消息、报告、通知 |
| 派发 Dispatch | 用户消息进入代理的过程与记录；策略为 steer / interrupt / queue |
| 引导 steer | 不打断当前执行，下一步采纳 |
| 打断 interrupt | 停止当前轮后立即处理新消息 |
| 排队 queue | 当前轮结束后再处理 |
| 权限模式 | confirm / standard / auto，决定哪些操作需审批 |
| 审批 Approval | 执行某个工具调用前请求用户批准 |
| 内容版本 Content version | 仅用于文本文件与外部修改检测的文件内容哈希；活文档内部以修订号标识版本 |
| 修订号 rev | 文档 actor 为每次提交分配的严格递增序号；文档内部的版本标识 |
| `baseRev` | 提交者据以工作的修订号，随提交携带，用于冲突检测 |
| 读集 / 写集 | 一次提交依据的读取区域 / 实际修改的区域；区域级冲突检测的输入 |
| ChangeSet | 一组类型化的工作簿修改操作，整批提交给文档 actor |
| 活文档 | 打开后在内存中被共同编辑的工作簿，由文档 actor 持有其模型 |
| 文档 actor | 一个活文档的唯一写入者：串行应用提交、分配修订号、增量重算公式、向订阅者广播 |
| 文档日志 | 活文档的只追加修订流（`doc_ops` 表）；xlsx 文件是它的检查点 |
| 检查点 Checkpoint | 把活文档当前状态保真写回 xlsx 的异步动作 |
| 对象层 | 持有 Univer 不建模对象（图表、透视表、切片器等）的 OOXML 与锚点并随结构操作维护其位置的层 |
| 只读大文件模式 | 超过活文档上限的工作簿不载入 Univer，由编解码层流式读取，不可编辑 |
| 会话日志 Session log | 每个会话只追加的记录序列，是会话状态的唯一事实源 |
| 投影 Projection | 从会话日志派生、可删除后重建的状态（模型上下文、界面时间线、待处理交互、代理状态等） |
| actor | 拥有私有状态与邮箱、逐条串行处理消息的有状态对象（Session、Agent、Document、Job） |
| 同步通道 | 客户端与后端之间的 WebSocket 通道：多主题订阅、会话日志与流式增量、文档操作、在线状态 |
| 主题 Topic | 同步通道上的订阅单元：`session:<id>`、`doc:<id>`、`app`，各带游标可续传 |
| 在线状态 Presence | 各客户端与代理正在查看/编辑哪个文档的哪个区域（协作光标） |
| 能力模块 | 以统一接口向内核注册工具、日志记录类型、投影、端点、主题、设置项等能力的模块 |
| 修改前备份 | 会话中首次修改已有文件前，运行时自动保存的原文件副本 |
| 回收站 Trash | 删除的文件被移入的位置，可恢复 |
| 变更摘要 Change summary | 运行时按本轮修订区间从文档日志生成的一轮结果摘要 |
| 活动叠加层 | 表格画布上显示代理读取/计划修改/已修改区域的图层 |
| 文件租约 Lease | 某代理对某文件或区域的写入独占声明；协调工具而非必需（区域级冲突已解决大部分重叠） |
| 会话日志记录 / 流式增量 | 持久的状态变化是会话日志中的一条记录（`rec`，可重放）；逐字文本、工具参数片段等是瞬时增量（`delta`，不入库、不重放） |
| 模型网关 Model gateway | 隔离第三方模型适配库的一层接口 |
| 模型档案 Model profile | 提供商、模型、凭据与参数的组合 |
| 能力探测 | 实测模型是否支持工具调用、视觉、思考 |
| 技能 Skill | 教代理某类工作方法的文档 |
| 工具说明 | 教代理某个工具用途与边界的说明文字 |
| 记忆 Memory | 跨会话保留的用户偏好、业务知识、文件说明、经验 |
| 规则 Rule | 用户写给代理的固定要求，注入系统提示词 |
| MCP | Model Context Protocol，接入外部工具的协议 |
| 快照 Snapshot | 工作簿的 Univer 数据结构（`IWorkbookData`），用于工作台加载、截图与文档打开重建 |
| 保真语料库 | 用于验证编解码不破坏文件的真实工作簿样本集 |
| spike | 正式开发前的技术验证 |
| ADR | Architecture Decision Record，架构决策记录 |
