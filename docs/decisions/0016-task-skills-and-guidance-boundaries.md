# ADR 0016：任务技能与软件指导内容归位

- 日期：2026-10-01
- 状态：已采纳（用户授权全面调整技能并约束后续开发）
- 影响：04 §7、06 §2/§10、12 §1、14 §6、15 §M5/M6b

## 背景

12 §1.1 与 04 §7.1 硬性区分任务技能和工具用法，但 12 §1.6 推荐清单包含产品能力说明与脚本运行契约。九个内置文件缺少真实效果证据，系统提示词又要求相关任务先加载，导致基础用法重复、静态能力过时与无价值的前置加载。

## 选项

1. 保留九个条目并扩写：无法解决基础契约多处维护。
2. 全部合并为一个大表格技能：触发范围过宽，独立任务的细节被一并加载。
3. 按内容职责归位，保留独立任务技能，按需读取情境资料，并区分机制和效果验收。

## 决定

采用选项 3。退役内置 excelmanus-guide 和 script-patterns；产品帮助进入 docs/user-guide.md 并在“外观与关于”显示同一源文件；脚本、代理角色/租约等基础行为在相关工具定义与契约中维护。七个任务技能重写判断、可选路线与核验，条件性实例放各技能 references/。技能数量不作为完成指标。

运行时提示按相关性按需加载，简单操作直接使用工具；不改变权限、工具集、来源覆盖与历史冻结。依赖检查同时覆盖声明和可识别的正文/参考引用，用户显式调用不能绕过不可用判定。通用社区 frontmatter 仍可导入，内容质量由评审与真实模型评测证明，不用禁词/篇幅门禁替代。

## 后果与同组验收标准

本项目增补 optional-tools frontmatter 字段标识有替代路线的设施，缺失时主任务仍可顺序完成；内置必需/可选工具名均做目录校验。此字段属于本项目扩展，通用社区格式无需声明。

- 仍兼容 SKILL.md 目录格式、名称/描述发现、skill 正文加载、read skill:// 资源、斜杠调用与来源覆盖；七个任务都有可复用入口和实例。
- 不增加知识门户或工具，不允许宿主代码执行，不读取或改写用户自装同名技能与旧日志；基础工具可脱离技能使用。
- 桌面自检验证存在且依赖可用，不再把“至少九个”当质量判据。历史验收保留原数字并加本轮记录链接。
- 机制以真实 HTTP/WS/SQLite + 假模型验证，投影可重建；内容价值必须对照真实模型任务。本轮无真实模型证据时保持未验证，不能宣称 12 §1.6/14 §6 已通过。
- 新开发约束与评审流程见 17；场景和结果见本轮验收记录。
