# ADR 0014：空工作簿与工具链一致性

- 日期：2026-10-01
- 状态：已决定（用户要求修复空工作簿创建及相关工具链）

## 背景

用户提供真实调用失败链：`create=true` 的默认 `Sheet1` 与 `sheet.add Sheet1` 冲突，转为 `ops=[]` 又被至少一个操作的限制拒绝。代理只能新增其他表再删除，删除结果将冲突检测用的整表区域误算为 17,179,869,184 格。工具回执、脚本预览、轮次摘要各有计数实现；总览使用导入计数，编辑后可能过期。

## 选项

1. 只在系统提示词中要求用无效写入或重算占位，维持非空操作限制。
2. 改为新建不含工作表，再要求代理显式新增至少一张表。
3. 保留默认空白 `Sheet1`，正式允许创建时空操作；共享参数与摘要机制，并回读当前修订。

## 决定

采用选项 3，不增加工具、不改变默认工作表、不静默吞掉重复 `sheet.add`。最小空工作簿创建为 `create=true + path + ops=[]`；修改已有工作簿仍拒绝空操作。工具及脚本说明明确默认表和改名语义，重复表错误提供纠正指引。创建预览验证相同路径约束，展示拟创建工作表和结构摘要；发布留下默认表新增修订与工具调用标识，即使没有单元格操作也能恢复为已提交。

文档 actor 在提交时统一生成变更摘要，脚本预览与工具回执复用；轮次摘要按日志汇总后使用同一函数。有限区域按并集计数，冲突哨兵保留但不作为修改格数；Excel 最后一行/列上的有限区域仍计数。删除工作表使用前像中的名称，编译时同步更新模拟工作表清单，禁止同批删光最后一张表；声明与引擎发射的工作表结构按身份合并，避免重复计数。总览和创建回执对当前快照统计值/公式，样式空格不算非空。

## 后果与验收

空文件无需写入占位数据、新增再删除表或重算。增加一条真实 HTTP/WS/SQLite + 假模型回归，覆盖失败纠正、空创建、回读、重叠写入、多表删除、最后一表保护、预览及重启；脚本回归覆盖预览、批准及发布。保留原有权限、备份、原子提交和不自动重放副作用边界。前端从真实结构摘要识别新建/结构修改，避免显示“已写入 0 格”。证据见 [本次验收](../acceptance/empty-workbook-tool-chain.md)，未验证真实模型自主决策的成功率。
