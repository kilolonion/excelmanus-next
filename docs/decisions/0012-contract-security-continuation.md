# ADR 0012：M6 契约与凭据安全续修

- 日期：2026-10-01
- 状态：已决定

## 背景

M6 审计发现凭据可能进入 HTTP 错误、结构化事件或 MCP 解密路径的全量登记集合；短凭据掩码也会泄露大部分内容。契约文档要求提供开发态 `/api/docs` 入口，但此前只有散落路由。

## 选项

1. 在每个调用点分别手写脱敏与契约描述。
2. 在服务边界统一脱敏，MCP 只登记实际解密值，并提供最小 OpenAPI 资源索引。

## 决定

采用选项 2：`maskSecret` 对长度不超过 8 的值全量掩码；HTTP 错误体、事件日志和账号错误在边界调用 `redactSecrets`；MCP 解密值按 apiKey 语义登记，避免把 env/headers 伪装成整组模型 headers；`GET /api/docs` 发布 OpenAPI 3.1 版本、认证方式和主要资源索引。DTO 的字段与请求/响应校验仍唯一来自 `@excelmanus/protocol`。

## 后果

凭据不再因错误或事件字段直接回显，短令牌不泄露尾部字符；`/api/docs` 可供开发工具发现入口，但详细 schema 仍由 protocol 契约生成，后续新增路由应同步更新索引。未验证 Windows 文件系统和生产反向代理部署。
