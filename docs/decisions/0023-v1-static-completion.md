# ADR 0023：V1 静态开发补齐与可复现验收

- 日期：2026-10-10
- 状态：已实现，待项目评审；不代表正式发布验收通过
- 基线：`b88d37aa1d46d0979aabb1cf63ab74f29c06141a`

## 背景

负责人要求按 docs 完成 Next V1，并选择不依赖浏览器的开发方式。审计发现，原有 M1–M5 的“实现完成”记录不能直接当作当前 V1 完成证明：除发布环境证据外，原生图表、规则、对象读取、文件管理入口和接口契约仍有实质缺口。本次增量完成这些代码，不更换文档 actor、事实日志、权限、备份或模型网关架构。

## 决定

1. 文件面板与 `files/manage` REST 复用原有 files 模块：路径守卫、活文档拒绝、备份、回收站与失败预检保持一致。删除需显式确认，上传可指定当前目录。
2. REST 契约在 protocol 注册，OpenAPI 从 Zod 生成；开发/测试响应按同一 schema 验证。启动时核对真实挂载路由，遗漏契约会失败。渲染 REST 接入原有 RenderBroker，无 renderer 时明确报错。
3. 图表/图片元数据存入 worksheet.custom，经前后端共享的、严格校验的 mutation 修改。导出器生成原生 DrawingML；不引入 Univer Pro。支持八类常见图表、图片新增和原始字节提取；导入图表只对可确定性处理的标题/数据引用做局部修改。未知 XML 保留，无法安全修改就拒绝。
4. 条件格式/验证采用 Univer 原生资源与 mutation，导出原生 OOXML；只编辑可建模规则，原有不支持规则保持字节片段。支持范围见当前验收记录。新增 em:id 与 mc:Ignorable 标识自有规则，避免按优先级猜测和误删第三方规则。
5. 行列尺寸、隐藏使用原生 mutation；分组级别采用共享轴元数据 mutation，写回 outlineLevel。分组的结构插删不能确定性保真时拒绝。排序采用引擎命令。查找替换在命令执行时读取实时内容，使同批先写值再替换正确；搜索串是字面量，不执行用户正则。
6. `workbook_read` 补样式、规则、对象提取、结构化行与有覆盖说明的静态依赖图；SQL 支持具名跨文件/表数据源，另提供差异和规则校验。SQL 在独立 Node 子进程运行，10 秒硬超时、128 MiB SQLite heap、只读数据库与输入/输出规模上限，避免递归查询或恶意正则阻塞主线程。桌面沿用 Electron run-as-node；当前 Linux 的 Node 实测不替代 Electron 实机测试。
7. 大工具结果继续保留完整事实日志；同工具 `result:seq:offset` 游标只读取原结果，不重执行写入。游标绑定会话、代理与工具；恢复时也按只读分页处理。
8. 诊断仅收集白名单元数据：结构化日志按日写入、本地 step/turn 关联、耗时和 usage。当前没有实现 OTel exporter 或完整 doc_op 分布式链路；明确记录与 03 §9 推荐方案的差异，不导出提示词、工具参数、文件内容或密钥。
9. 关闭后端先阻止新任务、取消并排空运行中 actor，再关闭数据库和文档。待审批/提问保留可恢复状态。对不响应 abort 的模型流，网关独立取消 reader，忽略迟到输出。
10. QuickJS 致命宿主/WASM 错误后退役整个 worker；不再对已经损坏的 VM 调析构器。正常资源仍显式释放。
11. 测试不删减。LibreOffice 原生进程并发在此环境导致资源失败，因此 Vitest 文件串行执行。测试内部并发写入/多代理仍保留。

共享对象/分组 mutation 要求同版客户端；同步协议升级为2。Web 对 bootstrap 和 hello 的版本不一致显示升级提示并停止进入工作台。

## 选项与取舍

- 不采用“每次改代码都部署”：本次全部本地 source-first 开发和真实后端自动化测试，无远端发布。
- 不以全绿测试代替真实模型质量、浏览器布局、签名安装/更新或固定硬件性能。
- 图表显示元数据占位框符合 07 §4.3；真实图表预览为 P1。本次图片也显示对象占位，原文件可提取；不声称浏览器渲染了完整 DrawingML。
- 06 推荐操作补齐 sheet.copy/move/hide、cells.fill、axis.size、filter.set、hyperlink.set。复制复杂对象/规则的表拒绝；自动适配采用确定性无头估算；筛选支持枚举/空值，其他原生规则保留但不解释；超链接以 cell custom 保存并转换为原生 OOXML。共享公式导入和填充时用 Univer 官方词法器展开，避免检查点丢失跟随单元格公式。
- `.xls/.xlsb` 导入与设置导入/导出的产品语义仍是附录 C 的开放项，未擅自决策。
